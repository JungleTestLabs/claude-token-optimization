## 一、新增发现（先前文档未覆盖）

### 1. 关闭闲置 MCP Server / 工具权限 ⭐ NEW

**来源**: CSDN文章 + 掘金文章

**问题**: 开发者为了功能丰富安装了各种 MCP Server，但不用时仍持续占用 Token。

```
❌ 开着但不用: 网页搜索、研究模式、连接器、各种MCP Server
→ 每次Claude回复都会额外消耗Token
```

**做法**:
- 用 `/context` 或 `/contextmini` 监控哪部分在消耗 Token
- 及时关闭当前不用的 MCP Server
- 日常禁用不必要的工具权限，仅在需要时开启
- 原则: **用啥开啥，不用就关**

**数据**: 开发者在 `/context` 中发现未关闭的 MCP Server 占用了大量 Token

---

### 2. token-efficient-tools beta header ⭐ NEW

**来源**: CSDN文章

**问题**: 工具调用（tool calls）的输出也会消耗大量 Token。

**做法**:
```
调用工具时添加 beta header:
token-efficient-tools-2025-02-19
```

**效果**: 可减少 **70%** 的工具调用输出 Token 消耗。

**适用**: Claude 3.7 Sonnet API 调用场景。

---

### 3. 编辑原提示词取代追加追问 ⭐ NEW

**来源**: 腾讯云文章（技巧三）

**问题**: 结果不对时追加追问，每条追问永久加入对话历史。10条追问 → 后续每次回复都要为这10条追问重复付费。

**做法**:
```
❌ 发追问: "这里改一下"、"那里不对"、"再加个XX"
   → 每条追问永久累积在对话历史中

✅ 编辑原提示词: 直接修改第一条提示词的编辑框，
   把修改需求补充进去，然后重新生成
   → 旧无效对话被替换，不堆冗余Token
```

**效果**: 多轮迭代场景可直接省掉 **50%** 的 Token 消耗。

---

### 4. Projects 项目功能 — 文件一次上传永久使用 ⭐ NEW

**来源**: 腾讯云文章（技巧六）

**问题**: 每次开新对话都重新上传同一份文件，文件内容每次都全额算 Token。

**做法**:
```
✅ 使用 Claude 自带的 Projects 项目功能
   把常用文件一次性上传到侧边栏的项目缓存里
   之后新对话直接调用，不用重复上传
```

**数据**: 一个100页的产品手册传一次花几千 Token，一个月传20次 = 几万 Token。用 Projects → 只花一次的钱，省掉 **95%** 的文件相关 Token 消耗。

---

### 5. 系统提示词"起步价"认知 ⭐ 数据补充

**来源**: CSDN文章

**新数据**: Claude Code 每次请求自动加载 **2-3万 Token** 的系统提示词（System Prompt）。这是每次交互的"固定起步价"，即使只是修改一个注释也要支付。

**意义**: 
- 解释了为什么小任务也有高消耗（之前文档只说 ~5K，实际可能是 20K-30K）
- 强调批量打包小任务的重要性

---

### 6. /context 和 /contextmini 监控命令 ⭐ 工具补充

**来源**: 掘金文章 + CSDN文章

**命令**:
```
/context      查看完整的上下文占用情况
/contextmini  查看精简版的上下文占用
```

**示例输出**:
```
使用 /context 查看: 总共200K的上下文占用了88% (176K)
使用 /compact 后:  55.7K, 占用了28%
```

**用法**: 定期监控 → 发现异常消耗来源（如未关闭的 MCP Server、冗余文件读取）

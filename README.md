# Claude Token 优化最佳实践

研究Claude Code及其他Claude工具中减少token消耗的方法论和实践。

## 项目目标

系统性地收集、分析、整理Claude token优化的各种方法，按类型分类：
- 配置优化
- 使用技巧
- 上下文管理
- 提示工程
- 工具链优化
